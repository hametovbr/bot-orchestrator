Handler

Handler reference

Define handle(update, ctx) (sync or async). It runs in bot-runner for every update a route sends here, in its own process, with a time limit. Type ctx. in the editor for suggestions.

update.message.textTelegram fields as attributes; a missing field is None. message.from_ is the sender. update.to_dict() gives the raw JSON. Scheduled runs get update.schedule (name, time, chat).
await ctx.reply(text, **params)Send a message to the chat of the update.
await ctx.reply_file(path, caption)Send a file to the chat: video, audio, photo or document by extension (up to 2 GB).
await ctx.api.send_message(chat_id=…, text=…)Any Bot API method, snake_case or camelCase. A Path is sent as a local file.
await ctx.answer_callback(text)Answer the callback query of the update.
task_id = await ctx.background(func, *args, title=…)Run func(ctx, *args) as a background task with a longer time limit. func must be defined at the top level of this code; arguments are JSON values.
await ctx.progress(text)Inside a task: progress shown on the Tasks tab.
await ctx.tasks.get(id), await ctx.tasks.cancel(id)Status of a task, or cancel it (e.g. from a button).
result = await ctx.download(url)Download video or audio with yt-dlp into downloads/, with a progress message in the chat. Options: audio_only, format, max_size_mb, cookies="/shared/cookies.txt", status, messages. Returns path, title, size, info.
await ctx.files.local_path(file_id)Download a Telegram file through the local Bot API server and get its path.
ctx.files.move(src, "inbox/name.pdf")Move or copy a file into the bot folder; existing names get a (1) suffix. Also write_text, write_bytes, read_text, list, path, safe_name.
await ctx.kv.get(key, default)Per-bot storage of JSON values; also set and delete.
ctx.secrets["NAME"]Secrets from the Settings tab.
ctx.log(...), print(...)Write to the update log.
await ctx.http.get(url)An httpx.AsyncClient for outside requests.
await ctx.shell("ffmpeg", …)Run a program in the bot folder; returns returncode, stdout, stderr.
from shared import nameCode from shared modules, common to all bots.
import pillow_heif, …Extra libraries from the Packages page.
