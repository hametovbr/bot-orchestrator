Handler reference

Define handle(update, ctx) (sync or async). It runs in bot-runner for every update the bot receives, in its own process, with a time limit.

update.message.textTelegram fields as attributes; a missing field is None. message.from_ is the sender. update.to_dict() gives the raw JSON.
await ctx.reply(text, **params)Send a message to the chat of the update.
await ctx.api.send_document(chat_id=…, document=path)Any Bot API method, snake_case or camelCase. A Path is sent as a local file (up to 2 GB).
await ctx.answer_callback(text)Answer the callback query of the update.
await ctx.files.local_path(file_id)Download a file through the local Bot API server and get its path on disk.
ctx.files.move(src, "inbox/name.pdf")Move or copy a file into the bot folder; existing names get a (1) suffix. Also write_text, write_bytes, read_text, list, path, safe_name.
await ctx.kv.get(key, default)Per-bot storage of JSON values; also set and delete.
ctx.secrets["NAME"]Secrets from the Settings tab.
ctx.log(...), print(...)Write to the update log.
await ctx.http.get(url)An httpx.AsyncClient for outside requests.
await ctx.shell("yt-dlp", url)Run a program in the bot folder; returns returncode, stdout, stderr.
