Packages

Extra Python libraries for all handlers and modules, in requirements.txt format. bot-runner installs them with uv into a separate folder and switches to it only when the install succeeds, so a failed install never breaks running bots. The runner's own libraries (httpx, yt-dlp, …) keep their versions.
